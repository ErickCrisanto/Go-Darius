# 🐉 GO DARIUS PRO

App educativa gamificada para niños de 3 a 8 años, pensada para apoyar el desarrollo del habla, la lectura, las matemáticas y el inglés.

✨ Todo en un solo archivo HTML, sin cuentas ni servidores.

## Mundos
- 😊 Emociones y frases para comunicarse
- ☀️ Contar el día · 📚 26 cuentos con preguntas de comprensión
- ✍️ Crear historias · 🔢 Sumas, restas y tablas de multiplicar
- 🇬🇧 Inglés: palabras, frases, números, traductor y dictado por voz
- 🎨 Pizarra para dibujar

## Cómo usarlo
1. Abre `index.html` en cualquier navegador (o publicarlo en GitHub Pages)
2. En Modo Papá: perfil, edad, niño/niña, estadísticas y diploma
3. El progreso se guarda en el navegador y puede exportarse a otro dispositivo

## Privacidad
Sin registro, sin anuncios, sin datos enviados a terceros. El micrófono y el traductor online solo se usan al tocarlos.
